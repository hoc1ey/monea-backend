# Assets de correo

Coloca aquí el logo de la aplicación con uno de estos nombres (el primero que exista se adjunta al correo):

- `logo.png` (recomendado)
- `logo.jpg`
- `logo.jpeg`
- `logo.webp`
- `logo.gif`

El archivo se adjunta como imagen embebida (CID) en las plantillas HTML. Si no existe ningún logo, los correos muestran el wordmark "MONEA" como respaldo.

Importante: el fondo del correo es negro puro (#000000). El logo debe ser un PNG con fondo transparente (canales alfa), nunca un PNG plano con fondo blanco o de color, porque la imagen se renderiza tal cual sobre el negro.

Recomendaciones: PNG cuadrado, mínimo 192x192 px (se muestra a 96x96), fondo transparente, menos de 200 KB.
