# Assets de correo

Coloca aquí el logo de la aplicación con uno de estos nombres (el primero que exista se adjunta al correo):

- `logo.png` (recomendado)
- `logo.jpg`
- `logo.jpeg`
- `logo.webp`
- `logo.gif`

El archivo se adjunta como imagen embebida (CID) en las plantillas HTML. Si no existe ningún logo, los correos muestran el nombre "Monea" como respaldo.

Recomendaciones: imagen cuadrada de al menos 144x144 px, fondo transparente o blanco, menos de 200 KB.
